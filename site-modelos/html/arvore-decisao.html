Last Mile Optimization
PCA Regressão Múltipla Árvore de Decisão Random Forest XGBoost

Objetivo

O modelo de Árvore de Decisão tem como objetivo prever se uma entrega será realizada dentro do prazo, representado pela variável delivered_on_time.

Lógica da Árvore de Decisão

condição → divisão → decisão final

Variáveis Independentes (Features)

Variáveis selecionadas para evitar redundância e vazamento de dados:

handling_time_hours, month, approval_time_hours, distance_km,
wind_gust, volume_cm3, freight_value, purchase_day_of_week,
geolocation_lat/lng, rainfall

Explicação

Macro → peso igual para todas as classes
Weighted → peso maior para a classe dominante (classe 1)

O modelo apresenta métricas altas em weighted, mas isso ocorre porque a classe 1 domina o dataset. Já a classe 0 (atrasos) continua sendo difícil de prever.

Conclusão

    Dataset

  • O dataset é fortemente desbalanceado, com predominância da classe 1. Isso faz com que métricas como accuracy e F1 weighted sejam infladas, mascarando o baixo desempenho na classe 0.

    • Modelo

  • A análise por classe evidencia o principal problema do modelo: baixa capacidade de identificar atrasos, com F1 da classe 0 de apenas 0.28 e recall de ~0.40, enquanto a classe 1 atinge F1 superior a 0.93.
  • O fato de o ajuste de limiar (0.22) não alterar as métricas indica que o modelo possui baixa separação entre as probabilidades das classes, reforçando a limitação estrutural da árvore de decisão simples neste problema.

    • Insights

  • O modelo inicial apresentou excelente desempenho global (F1 weighted = 0.9172), porém com overfitting significativo (gap de ~8%), indicando que ele decorou os dados de treino e possui menor capacidade de generalização.
  • As features mais importantes mostram que fatores operacionais como tempo de manuseio, mês, tempo de aprovação e distância são mais relevantes que variáveis externas isoladas.

    • Top features:
      handling_time_hours → 0.1899 (muito dominante)
      month → 0.0858
      approval_time_hours → 0.0770
      distance_km → 0.0694


  • Do ponto de vista de negócio, o modelo atual é mais eficiente para confirmar entregas no prazo, mas ainda é limitado para antecipar atrasos, que são os eventos mais críticos.
